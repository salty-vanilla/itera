# Itera

1 週間ごとに「何を達成したいか」と「どこまでなら現実的か」を決め、日々実行し、結果から次の計画の立て方を少しずつ改善するための個人向けアプリ。`Backlog → Planning → Today → Retro → 次の Planning` の循環を支える。

現在は設計文書と開発環境を整えている段階で、アプリのコードはまだない。
